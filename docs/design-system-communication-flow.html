ProtectedRoute Decision Flow
1

Call useCurrentUser()

Fetches /me via React Query. staleTime: Infinity — loaded once per session.

2

status === "error"?

→ navigate('/login', replace: true). Triggered by 401 inside ErrorRequest.handleError().

3

status === "pending"?

→ Render loading skeleton (implicit antd Skeleton).

4

permission missing?

→ Render <Result status="403" /> — user is authenticated but lacks the required permission.

5

All checks pass

→ Render {children} — the page component loads.

Permissions live on User.permissions: Permission[]. The server is the source of truth — the client guard is UX only.

HTTP Stack

Fluent builder: .withMethod().withUrl().withParams().send(). Returns Promise<T>.

On HTTP 401 → router.navigate('/login', replace) then re-throws. All other errors re-thrown.

4

One file per domain: accounts.ts, auth.ts, transactions.ts, transfers.ts, insights.ts, user.ts

5

Mock Backend src/api/mock/mockBackend.ts

Installed when VITE_API_BASE_URL is unset. axios-mock-adapter with 300ms delay, in-memory data, business rule enforcement.

Slide 7 of 10 · Forms
Form Communication Flow
Ant Design Form with live preview via Form.useWatch
Transfer Page — Live Preview Pattern
1

TransferForm owns the Form instance

Form.useForm<TransferFormValues>() creates a controlled form with programmatic access.

2

Form.useWatch reads live values

Form.useWatch('fromAccountId', form) — re-renders only when the watched field changes. Used by useTransferForm hook.

3

Values passed as props to TransferSummary

No shared state, no context — parent page passes watched values down as explicit props.

4

Cross-field validation

toAccountId has a custom validator that rejects the same value as fromAccountId. form.resetFields(['toAccountId']) is called on source change.

5

onFinish → useMutation → ResultTransfer

On submit: useTransferFunds.mutate(values). On success: store result in local state, render <ResultTransfer> with new balances.

Tailwind + Ant Design Coexistence

The Problem

Ant Design v6 uses CSS-in-JS injected in <head> without cascade layers. Tailwind utilities (also unlayered) at the same specificity level → unpredictable wins.

The Fix

tailwind.config.ts sets important: true → all Tailwind utilities are marked !important, ensuring they always override Ant Design defaults.

// tailwind.config.ts export default { important: true, // defeats antd specificity content: ['./src/**/*.{tsx,ts}'], ... }
Ant Design Theme Config
// src/context/theme/index.ts const themeConfig: ThemeConfig = { token: { colorPrimary: '#1d39c4', }, components: { Typography: { titleMarginBottom: 0, }, }, }; // Injected in App.tsx: <ConfigProvider theme={themeConfig}> {/* entire app */} </ConfigProvider>

Slide 10 of 10 · Summary
Key Design Patterns at a Glance
The communication contracts the design system is built on

Unidirectional Data Flow

Props always flow down. Children communicate up via callbacks passed as props. No sibling-to-sibling direct communication — they both read from the same query cache.

Server State as Source of Truth

No Redux, no Zustand. React Query's QueryClient is the single source of truth for all remote data. Cache keys are the "addresses" data lives at.

Builder Pattern for HTTP

RequestBuilder composes HTTP calls fluently, making every request declarative and easy to test. The 401 handler is separated into ErrorRequest (single-responsibility).

Atomic Wrapper Layer

Antd components are never imported directly in feature code. The atomic layer provides a stable internal API — if Ant Design changes, only the wrapper changes.

Permission-Based Guard

User.permissions[] array from the server controls what pages render. ProtectedRoute is a UX guard — it relies on the HTTP layer and the backend for real security.

Form.useWatch for Live Preview

Transfer page uses Form.useWatch to read live field values into a sibling summary component — no extra state, no context, just Ant Design's built-in reactive subscription.
